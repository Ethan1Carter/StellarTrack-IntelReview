# 星轨智评 Sites 独立演示版

这是由原 Vue 项目整理出的独立演示版本。用户已选择使用示例数据；没有连接 Express、PostgreSQL、真实 AI 服务或师生上传目录。

入口提供学生、班级管理员、辅导员、学院管理员四种示例身份。可体验申报编辑与提交、同成果提醒、材料与预置分析对照、审批、综测解释、配置试算、成长记录与教师反馈、统一待办。演示操作保存在本站当前浏览器的本地存储中；不同浏览器之间不共享，可以从页面顶部重置示例。

所有人名、规则、成绩和证书均为示例。内置“演示证书”用于材料预览；不接收个人附件，不执行真实文件指纹识别。未开放的上传、导出、申诉和系统管理操作会明确拒绝，不表示已完成实际操作。预置材料分析不是实时 AI 识别结果。

## 本地验证

```sh
npm ci
npm test
npm run build
npm run preview -- --host 127.0.0.1
```

自动化检查覆盖演示流程与本地状态变化；不替代原项目后端测试或真实师生试用。安全数学公式解析器由原后端纯函数移植为浏览器模块，未使用 eval。

`.openai/hosting.json` 保存已有 Sites 项目身份。继续更新应复用该 project_id，不要重新注册。站点初始仅所有者可访问；不要为了发布改变访问范围。
