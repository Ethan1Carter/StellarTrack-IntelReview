# 制度知识库与校园活动优化说明

本轮在源码修改前，已把当前源码备份到 GitHub 独立分支 `codex/backup-before-knowledge-activities-20261021`，并核验远端提交为 `e2f7f0b366c5490be495faa2c02828d53fb47613`。源码快照不含真实环境配置、师生附件或数据库备份。

## 本轮能力

- 学生可在「制度问答与原文」按学年查询本院系适用的已发布制度，连续追问，并查看原文片段、段落、文号、发布单位、来源链接和版本。没有匹配依据时明确无法确认；采用原文检索摘录，不是大模型生成回答。
- 「校园活动与实践机会」按五育方向、可用时长及关键词筛选当前适用活动，展示推荐理由、时间和来源。学生可将活动加入已有学期成长计划；重复加入、过期、撤回和计划版本冲突均有检查。加入计划不等于报名、获得名额或综测加分。
- 管理员可按院系维护制度与活动草稿，核对来源后发布，创建修订版或填写原因撤回。已发布正文不能覆盖，修订保留历史版本；核对勾选是管理员确认，不代表平台已独立认证其权威性。
- 提供匿名试用 CSV 空模板、记录指南与离线汇总脚本。每项指标按有效样本分别计算分母，缺测不记为零，也保留耗时增加的结果。尚未进行真实师生试用，不提供虚构准确率或效率结论。

真实接口根据登录身份限制学校、院系和学生范围，不采信学生提交的院系或用户编号。发布、修订、撤回与加入计划使用事务及版本检查；审计仅记录必要操作信息，不记录问答正文。

## 正式系统升级条件

新增 `guidance_resources` 资源表。迁移脚本已准备，**本轮未执行迁移、未修改日常数据库，也未重启或发布原业务服务**。现有库未建表时，相关页面会提示需要升级。

维护者取得数据库升级授权、确认目标库并完成业务数据备份后，才可在项目根目录执行：

```sh
node server/scripts/migrate-guidance.js --apply
```

脚本仅创建新增资源表，不覆盖旧表、不插入示例数据。随后部署相匹配的前后端，由校方管理员录入并核对真实制度与活动来源。应用不会自动抓取或编造校方文件、活动名额和计分承诺。

## Sites 演示

已发布第 2 版至 https://xinggui-intelreview.ajhz217.chatgpt.site ，Sites 源码提交为 `89dec91e8ae91368d0b58242392e06166ad5b2c0`。发布时读取到既有范围包含所有者及已授权访问者，沿用该范围，未新增访问权限。

- 原项目 `npm test` 共 67 项通过；Sites 演示测试共 9 项通过，两个前端构建通过。
