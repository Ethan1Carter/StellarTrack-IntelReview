## 规则查询与申报指引

学生和班级管理员通过侧栏“规则查询与申报指引”进入 `/rule-guide`。

- 根据鉴权账号的院系、年级、专业和班级筛选启用中的适用模块，不接受客户端指定其他学生或扩大院系范围。
- 输入活动或成果问题后，按关键词及常见活动同义词检索当前配置；显示相关原文、完整正文、版本摘要、更新时间、上限和必备材料。
- 引文直接取自模块配置，不调用模型生成制度条款；没有对应规则时提示咨询教师，不推断应得分数。
- 单次、学年和次数上限单独显示，不将上限解释为可认定分值。
- 可进入仍然适用的对应申报模块；具体分值留空，需本人核对填写，不自动提交。
- 管理员配置未认证为学校正式制度。模块尚未独立维护正式制度的发布主体、适用学年与批准版本，本轮不宣称建立官方制度知识库或完成 RAG。

## 个性化成长计划

学生在保存本期计划前，可以选择关注方向、已参与情况、每周预计可投入时间及个人目标，预览后再保存。

- “已经参与，主要补充记录”生成整理已有经历、补充证明和反思的任务，不要求为补齐记录而重复参与。
- “先确认已有参与情况”先安排确认记录；没有记录不解释为没有参与。
- 采用学生主动选择的方向；没有主动选择时，仍只从当前记录提供起点，不将不同量纲分数用于能力高低排序。
- 偏好保存在既有 `diagnosis` JSON 快照中；预览不创建正式计划，保存后不因再次生成而覆盖已有任务或证据。
- 起始期限从生成时计算，时间安排属于规则模板，教师可结合实际调整，不等于学校活动日期或强制时长。
- 有范围权限的教师可调整待开始、进行中、待补充任务的名称及日期，必须填写原因，保留前后定义、操作人、时间、学生执行记录和证明。
- 待核验或已完成任务不能直接改写；调整继续使用事务行锁和版本号，自身核验和越权修改继续拒绝。
