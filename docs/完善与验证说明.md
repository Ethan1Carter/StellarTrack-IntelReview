# 项目完善与验证说明

日期：2026-10-19。

## 本轮完成

1. 学校管理员的作用域从平台全局改为本校院系与班级。增加异步请求上下文中的数据库约束，覆盖列表、单条读取、关联查询、计数、SUM/MIN/MAX、批量写入及增减操作；平台管理员不受该学校边界限制。没有绑定学校的校管拒绝访问。
2. 用户管理同时校验目标账号当前角色、最终角色及学校/院系/班级归属。校管不能编辑同级和上级账号；院管不能编辑院管或更高角色；内部审批字段、主键和登录记录不再接受表单批量赋值。本人资料更新保留在个人中心。
3. `/auth/me` 移除密码哈希、身份证及登录 IP。附件使用独立路径的 HttpOnly 登录 Cookie，仍核验 JWT 和当前账号状态；该 Cookie 不授予业务写操作权限。
4. 上传目录只使用服务端鉴权用户 ID，收紧扩展名与声明 MIME 的组合。附件访问检查真实文件路径、登录状态和业务关联；学生不能凭同班身份读取他人材料；禁止通过引用他人上传链接获取材料访问权限。历史目录数字不作为上传人凭据。
5. 两个用户 Excel 导入地址共享处理函数，使用 Excel 上传器；校验每行角色与归属，防止覆盖其他学校或上级账号；按行事务同步班级管理员绑定，显示行号错误，清理导入临时文件，单次最多 5000 行。
6. 数据库备份全部操作及对应菜单仅向超管/开发者开放。数据库客户端通过参数数组调用，凭据通过环境变量传递。PostgreSQL 恢复遇到 SQL 错误即失败并在单个事务中执行；MySQL 使用自己的客户端。恢复前先安全备份，同一后端进程仅执行一个恢复任务，并保留恢复结果记录。
7. 部署打包排除 `.env*` 真实配置、配置备份、材料、数据文件与常见密钥文件，仅保留 `.env.example`；前端生产配置重新生成为 `/api`。不跟随链接；临时目录使用唯一名称且删除前检查边界；已有部署包不覆盖。后端启动脚本定位到 `server`，检查依赖安装与启动退出状态，兼容 Windows PowerShell 的 UTF-8 编码。
8. 网络超时不清空登录，明确 401 才清理；避免退出接口的 401 递归。退出时清除当前账号的 AI 材料暂存。
9. 切换班级、学生或学期后使旧 AI 报告失效，迟到响应不能覆盖新筛选。分析与导出传递相同的学生范围和学年学期，导出也核验学生权限；终审驳回不再计入 AI 报告的终审通过数。
10. 申报附件清单双向同步，上传期间禁止保存或提交，移除后的迟到上传结果不再带回。编辑申报使用完整清单替换，避免重复追加附件。
11. AI 材料清单按账号在当前浏览器标签页暂存，返回页面可恢复；中断的分析恢复为待处理。单份申报成功或保存草稿后更新批次状态，避免继续批量生成同一条申报。审核人员不再显示学生专用申报按钮。
12. 增加根目录统一测试命令；会写库的旧综测测试不再自动读取日常 `.env`，需显式指定测试库，断言失败返回非零退出码。

## 验证方式

根目录运行：

```text
npm test
npm run build
```

新增测试使用模拟数据库、Sequelize 查询条件以及本机临时 HTTP 服务，覆盖权限拒绝、并发请求隔离、校管本人资料、附件目录、材料授权、真实 Excel 上传路由、前端状态恢复、请求竞态、打包清单和测试库保护。临时上传目录会清理。

已有公式解析、作用域矩阵、角色一致性及静态一致性检查也已运行。新增测试另外覆盖学校角色的实际作用域解析。

## 部署条件与实际边界

- 需要学校与院系归属数据正确。可检查已有 `migrate-add-schools.sql` 的升级说明；本轮没有执行数据库迁移、修改日常数据库或启动生产服务。
- API 和材料建议同源部署，使用现有 Nginx 示例代理两个路径；不要以静态目录别名绕过后端附件鉴权。原生客户端读取材料时可使用 Bearer Token。
- 学校边界针对学校管理员统一加固。平台共享资源保留读取语义；后续仍应在独立测试库中验证所有角色的跨校通知、公示及历史数据策略。
- 备份恢复需要先停止业务写入，在维护环境验证；本轮验证了权限与命令构造，没有执行真实恢复。恢复锁属于单进程，多个后端实例需增加跨实例维护锁。旧 SQL 文件可能不含清理语句，应先在空的隔离数据库验证兼容性。
- 已有数据库升级脚本仍需人工按历史版本执行；尚未实现统一版本化迁移。
- PDF 正文提取、OCR 页码证据、成长计划的执行记录和教师复盘属于下一轮功能工作，本轮未将它们标记为完成。
- 前端生产构建仍有已有的 Sass 弃用提示与导入拆包提示，不影响本次构建通过。
