## 本轮功能

在“审批中心 → 核对材料/流程”打开审核工作台：

1. 桌面同屏展示附件与申报/建议对照，手机切换为单栏；图片支持放大，PDF 支持页码和新窗口查看。
2. 对照标题、日期、证书编号、获奖级别、模块、分值，突出不同内容；保留零分，不将缺失建议显示为一致。
3. 点击事实或原文旁的页码，定位分析时记录的那一份附件；原件不在当前附件清单时暂停定位，不跳到其他材料。
4. 展示身份核验提示、学生人工核对说明、分析时的规则原文及版本；当前模块配置单独展开，提示核对适用学年。
5. 退回补充可插入材料清晰度、成员证明、评分依据、成果日期四类常用要求。保留原意见、避免重复添加，超过 500 字时提示精简，不截断文字。
6. 学生资料、流程及历史意见改为可展开区域，申诉中的记录默认展开。原有通过、退回、驳回、终审和申诉处理仍调用已有接口。
